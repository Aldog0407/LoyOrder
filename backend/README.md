# Backend

API REST de LoyOrder. La implementación se hará en la tarea 7.1.3 después de decidir el stack y el modelo de datos.

Capas previstas:
- `presentation/`: controladores o rutas HTTP.
- `application/`: casos de uso y coordinación de operaciones.
- `domain/`: entidades y reglas del negocio.
- `infrastructure/`: persistencia y servicios externos como Loyverse, correo e impresión.

Esta es una propuesta de organización inicial, no una arquitectura aprobada todavía.
